# Implementation roadmap

| Phase | Scope | Exit criteria |
| --- | --- | --- |
| 0 | Planning and ownership | Confirm MVP scope and team responsibilities. |
| 1 | Foundation | Install, lint, typecheck, test and build the public shell. Verify the Prisma baseline. |
| 2 | Course management | Authorized staff manage and publish courses. Public pages expose published courses and support search and filtering. |
| 3 | Institutional CMS | Staff edit institutional content. Public pages expose approved content. Verify course regressions. |
| 4 | Inquiries and admissions | Public forms persist valid submissions. Authorized staff review and update their queues. |
| 5 | Release | Verify staging, accessibility, backups, deployment and production smoke checks. |

Phase 2 follows foundation readiness and staff authentication decisions. Phase 3 follows completion and verification of Phase 2.
